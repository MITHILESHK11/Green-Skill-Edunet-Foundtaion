# 🌱 Green Skill Edunet Foundation: Energy Consumption & Environmental Analysis

This repository contains a series of Jupyter Notebooks and datasets aimed at analyzing energy consumption patterns and environmental factors. The project is part of the Green Skill Development Program under the Edunet Foundation initiative.

---

## 📁 Repository Structure

- `day1.ipynb` to `day5.ipynb`: Sequential notebooks covering various aspects of data analysis and modeling.
- `day4dl.ipynb`: Deep learning models applied to energy consumption data.
- `appliance_energy.csv`: Dataset containing appliance energy usage statistics.
- `environmental_factors[1].csv`: Data on environmental factors influencing energy consumption.
- `green_tech_data[1].csv`: Information on green technologies and their impact.
- `predict_energy_consumption[1].xlsx`: Excel file with predictive modeling results.

---

## 📊 Project Objectives

- Analyze appliance energy consumption data to identify usage patterns.
- Explore environmental factors affecting energy usage.
- Develop predictive models to forecast energy consumption.
- Apply deep learning techniques for enhanced prediction accuracy.
- Promote green skills through practical data science applications.

## 📌 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MITHILESHK11/Green-Skill-Edunet-Foundtaion.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Green-Skill-Edunet-Foundtaion
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Open the notebooks using Jupyter:
   ```bash
   jupyter notebook
   ```
